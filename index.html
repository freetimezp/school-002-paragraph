01 — THE BASICS

Meet the paragraph.

One element. One thought. A foundation for readable content.

01.1

The HTML element

The <p> element represents a paragraph. Use it to group related sentences into a meaningful block. 

                            
                                <p>
                                Learning to code takes practice.
                                </p>
01.2

Separate your thoughts

Use separate paragraph elements for separate ideas. Browsers normally display them as distinct blocks. 

                            
                                <p>First thought.</p>
                                <p>Another thought.</p>
01.3

Spacing is not content

Don't add empty paragraphs just to create gaps. Use CSS margins to control the space between blocks. 

                            
                                p {
                                    margin-bottom: 1.5rem;
                                }

FIELD NOTES / 002 READING EXPERIENCE

The art of slowing down.

Good design is not always about adding more. Sometimes, it is about giving every element enough room to breathe.

A comfortable reading experience comes from the details: the size of the letters, the distance between lines, and the width of the column they occupy.

Adjust these settings and notice how the exact same words can feel crowded, calm, elegant, or difficult to follow.

03 — THE PRINCIPLES

Three things to remember.

Aa 01 / SIZE

Make it readable.

Font size determines how large the characters appear. Body text often starts around 16–18px, but the right choice depends on the font and reading context.

font-size: 18px;
↕ 02 / RHYTHM

Give lines room.

Line height controls the height of each line box. A unitless value around 1.5–1.7 is a useful starting point for many paragraphs.

line-height: 1.6;
↔ 03 / WIDTH

Control the measure.

Long lines can make it harder to track the next line. Limit paragraph width and adjust it for different screens and fonts.

max-width: 65ch;
