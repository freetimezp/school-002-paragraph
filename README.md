# School 002 — Paragraph Typography

An interactive beginner lesson about HTML paragraphs and readable text, built with HTML, CSS, and vanilla JavaScript.

## Live Demo

https://freetimezp.github.io/school-002-paragraph/

## Topics Covered

- HTML paragraph element: `<p>`
- Paragraph structure and separation
- CSS `font-size`
- CSS `font-family`
- CSS `font-weight`
- CSS `line-height`
- CSS `max-width`
- Paragraph margins and spacing
- Readable text and responsive typography

## Features

- Interactive typography playground
- Live paragraph preview
- Adjustable font size, line height, and width
- Font family and weight controls
- Reset settings button
- Three-question knowledge check
- Randomized answer options
- Instant feedback and explanations
- Responsive layout
- Accessible focus states and reduced-motion support

## Project Structure

```text
school-002-paragraph/
```

## Run Locally

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Experiment with the typography controls.
4. Complete the knowledge check.

No build tools or JavaScript dependencies are required.
